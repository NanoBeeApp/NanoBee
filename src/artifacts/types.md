# artifacts/types.ts

## Responsibility
Shared domain types for Artifacts. An Artifact is a piece of data dynamically generated by a chat message (currently always wrapping a card deck); the envelope is intentionally decoupled from the deck to allow other payload types in the future.

## Core exports / API
- `Artifact`: the full artifact record (id / kind / title / cardCount / deck / chatId? / favorited / createdAt)
- `ArtifactRef`: a lightweight reference (id / kind / title / cardCount) attached to the AI chat message that generated it; clicking it opens the Artifacts page

## Dependencies
- Upstream: `cards/types.ts` (CardDeck / CardKind)
- Downstream: `worker/artifacts/repo.ts`, `worker/agent/card-artifact-tools.ts`, `worker/routes/artifacts.ts`, `store/useAppStore.ts`, `components/artifacts/*`, `components/chat/ArtifactRefCard.tsx`, `types.ts` (AiMessage.artifacts)

## Key implementation notes
- Platform-agnostic; shared between worker and client
- `ArtifactRef` carries only the minimum fields needed for display; the full deck is loaded on demand when the Artifacts page opens

## Change history

### 2026-06-13 — Created
- **Motivation**: the interaction model changed to "chat triggers generation + dedicated Artifacts page collects results"; a generated card list is a piece of dynamic data (an artifact)
- **Goal**: define the artifact envelope type and the in-chat reference type
- **Key decisions**: envelope decoupled from deck — initially only carries a card deck; reference separated from the full record so the chat stream stays lightweight

### 2026-06-15 — Added `favorited`
- **Motivation**: the Artifacts page gained a Your favorites tab, requiring the favorited state to be carried on `Artifact`
- **Goal**: add `favorited: boolean` to `Artifact`
- **Key decisions**: stored as an envelope field rather than a separate reference type so that list responses include favorited state and the frontend can filter directly on it

### 2026-06-15 — 纠偏为「数据视图」判别联合（P1）
- **Motivation**: Artifacts 实际产品是「聊天生成数据视图」，不是背单词卡组
- **Goal**: `Artifact` 改为判别联合 `DataViewArtifact | WordDeckArtifact`；新增 `DataViewArtifact`（source/query/pipelineStatus/itemCount/defaultView/topicId/lastFetchedAt/errorText）、`DataViewItem`、`PipelineStatus`；`ArtifactRef` 改为按 `kind` 双分支
- **Key decisions**: word 分支仅保留兼容旧数据渲染，不再新建；FeedQuery 类型抽到 `feed-query.ts`。权威契约见 `private/docs/artifacts-data-views-design.md`
