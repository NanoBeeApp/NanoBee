# DataViewListPane.tsx

The list view of a data view's item stream: a flat, feed-style list (no card
boxes) — title link + optional summary + a meta line (source badge · author ·
points · comments · time), hairline separated. Pure render.

## 变更历史与出发点
- 2026-06-15 新建（P1）。遵守「列表/feed 平铺、禁卡片堆砌」铁律（参考 Twitter）。
